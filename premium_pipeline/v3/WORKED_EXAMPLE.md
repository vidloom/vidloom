# Worked example: one pan variable

This is a planning example, not a tested recipe or an experiment we performed.
It must not pass production review as written.

## An answerable question

Audience: home cooks disappointed by pale pan-cooked food. Question: with the
same ingredient batch and heat, what changes when the pan is crowded? Benefit:
recognize an observable difference and choose a useful action. Contribution:
an honest recorded comparison with conditions disclosed.

Three opening candidates, conditional on having the footage:

- "Same batch, same heat. Only the spacing changed." Requires a controlled setup.
- "Which pan would you choose?" Requires readable side-by-side outcomes immediately.
- "I changed one thing between these two pans." Requires evidence that other
  relevant conditions were held equal; otherwise narrow the claim.

Reject "This trick guarantees restaurant potatoes": neither the result nor its
scope is established. Select the hook after inspecting the recordings.

## Coverage before narration

| Beat | Required evidence | Disqualifier |
| --- | --- | --- |
| Opening | Actual outcomes, same ingredient/preparation | Scallops in one pan, potatoes in another |
| Setup | Same batch split, documented heat/time, spacing | Unrelated stock sessions portrayed as one experiment |
| Observation | Matched-time surface and moisture views | Only an attractive plated shot |
| Explanation | Verified reference and consistent footage | Temperature inferred from bubbling |
| Payoff | Actual result and limitations | Synthetic crunch presented as measured texture |

If evidence is missing, output the exact capture list. For example: "Need a
continuous recording of each pan, matched checkpoints, a final side-by-side and
real contact audio. The existing washing, cutting and scallop clips cannot
establish this comparison." Do not assemble a replacement montage.

## Connected speech after observing

"These started from the same batch. I [documented difference]. At [measured
checkpoint], this pan [literal observed result], while the other [literal observed
result]. [Supported explanation and relevant limit]. So if you're trying to
[viewer goal], [action justified by the comparison]."

Replace brackets with observed facts. Do not fabricate a favorable result. An
inconclusive experiment needs an honest conclusion or a different useful story.

## Timing and composition

If the accepted take says "only the spacing changed" from measured 2.18 to 3.42
seconds, matching evidence at 30 FPS must cover at least output frames [65,103).
A correct picture that appears later still fails. Never invent these times
before recording.

If both pans do not fit a vertical crop, make a labeled comparison layout as an
explicit source asset or film a composition that shows both. Do not crop away
one outcome and imply a visible comparison. Hold the result long enough to see
the difference. Captions come from aligned words; measurements need documentation.
Music may step back for the real pan sound. Added crunch proves nothing here.

## Falsifiable review notes

Bad: "Looks premium, great hook, approved."

Useful, only after inspection: "At output 2.18–3.42s both source recordings show
the logged checkpoint. The labels match the pans and the spacing difference is
visible. Both surfaces remain in frame. Color is not used to claim interior
doneness."

The validator checks references and times; it cannot witness the experiment.
